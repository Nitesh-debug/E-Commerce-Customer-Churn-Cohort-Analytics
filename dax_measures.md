# Power BI Business Intelligence Readiness: Essential DAX Measures

This document provides a comprehensive library of production-ready **Data Analysis Expressions (DAX)** measures designed for Power BI dashboards connecting to the `analytics.db` database or the exported analytical tables in `output/`.

---

## 1. Recommended Data Model (Star Schema)

For optimal Power BI performance, organize tables into a star schema:
- **`FactTransactions`**: Cleaned records from `transactions` table in `analytics.db`.
- **`DimCustomer`**: Customer master table including RFM segments and ML churn risk scores (`output/customer_churn_predictions.csv` & `output/rfm_customer_segments.csv`).
- **`DimDate`**: Standard contiguous calendar table (`Date`, `Year`, `Month`, `YearMonth`, `Quarter`).
- **`DimProduct`**: Unique products derived from `StockCode` and `Description`.

## 2. Core Sales & Volume DAX Measures

### [Total Sales]
Total monetary revenue generated across all transactions.
```dax
Total Sales = 
SUM(FactTransactions[TotalAmount])
```

### [Total Quantity Sold]
Total volume of product units sold.
```dax
Total Quantity Sold = 
SUM(FactTransactions[Quantity])
```

### [Total Orders]
Total count of unique invoice orders.
```dax
Total Orders = 
DISTINCTCOUNT(FactTransactions[InvoiceNo])
```

### [Average Order Value (AOV)]
Average revenue per completed order.
```dax
Average Order Value (AOV) = 
DIVIDE([Total Sales], [Total Orders], 0)
```

### [Average Basket Size]
Average number of items per completed order.
```dax
Average Basket Size = 
DIVIDE([Total Quantity Sold], [Total Orders], 0)
```

## 3. Customer Activity & Churn Metrics

### [Total Customers]
Unique count of customers who have transacted in the system.
```dax
Total Customers = 
DISTINCTCOUNT(DimCustomer[CustomerID])
```

### [Active Customers (90 Days)]
Customers who made at least one purchase within the trailing 90 days of the selected snapshot date.
```dax
Active Customers (90 Days) = 
CALCULATE(
    DISTINCTCOUNT(FactTransactions[CustomerID]),
    DATESINPERIOD(
        DimDate[Date],
        MAX(FactTransactions[InvoiceDate]),
        -90,
        DAY
    )
)
```

### [Churned Customers Count]
Count of customers whose last transaction date was more than 90 days ago.
```dax
Churned Customers Count = 
CALCULATE(
    DISTINCTCOUNT(DimCustomer[CustomerID]),
    DimCustomer[Is_Churned] = 1
)
```

### [Churn Rate %]
Percentage of the customer base classified as churned.
```dax
Churn Rate % = 
DIVIDE([Churned Customers Count], [Total Customers], 0)
```

### [At-Risk Customers Count]
Customers categorized in the RFM 'At-Risk' segment (previously active/high spenders who are slipping away).
```dax
At-Risk Customers Count = 
CALCULATE(
    DISTINCTCOUNT(DimCustomer[CustomerID]),
    DimCustomer[Customer_Segment] = "At-Risk"
)
```

### [At-Risk Revenue Exposure]
Total historical revenue generated by customers who are currently in the 'At-Risk' segment.
```dax
At-Risk Revenue Exposure = 
CALCULATE(
    [Total Sales],
    DimCustomer[Customer_Segment] = "At-Risk"
)
```

### [Predicted High Risk Customers (ML)]
Customers identified by the Random Forest classifier with Churn Probability > 70%.
```dax
Predicted High Risk Customers = 
CALCULATE(
    DISTINCTCOUNT(DimCustomer[CustomerID]),
    DimCustomer[Risk_Level] = "High Risk"
)
```

### [Predicted High Risk %]
Percentage of the active customer base flagged at high risk of churning by the ML model.
```dax
Predicted High Risk % = 
DIVIDE([Predicted High Risk Customers], [Total Customers], 0)
```

## 4. Customer Lifetime Value (CLV) & Unit Economics

### [Average Revenue Per Customer (ARPU)]
Average monetary revenue contributed by each customer.
```dax
ARPU = 
DIVIDE([Total Sales], [Total Customers], 0)
```

### [Purchase Frequency]
Average number of orders placed per customer.
```dax
Purchase Frequency = 
DIVIDE([Total Orders], [Total Customers], 0)
```

### [Average Customer Lifespan (Months)]
Average duration (in months) between a customer's first and last recorded transactions.
```dax
Avg Customer Lifespan (Months) = 
AVERAGEX(
    DimCustomer,
    DIVIDE(
        DATEDIFF(DimCustomer[FirstPurchaseDate], DimCustomer[LastPurchaseDate], DAY),
        30.44,
        0
    )
)
```

### [Customer Lifetime Value (Historic CLV)]
Customer Lifetime Value calculated from historical transactional value.
```dax
Historic CLV = 
[Average Order Value (AOV)] * [Purchase Frequency]
```

### [Predictive CLV]
Forward-looking Customer Lifetime Value incorporating churn retention probability.
```dax
Predictive CLV = 
DIVIDE(
    [ARPU],
    IF([Churn Rate %] = 0, 0.05, [Churn Rate %]),
    0
)
```

## 5. RFM & Cohort Retention Measures

### [Champions Revenue Share %]
Proportion of total sales originating from top-tier "Champions" customers.
```dax
Champions Revenue Share % = 
DIVIDE(
    CALCULATE([Total Sales], DimCustomer[Customer_Segment] = "Champions"),
    [Total Sales],
    0
)
```

### [Cohort Size]
Initial customer count for a monthly acquisition cohort (Cohort Month).
```dax
Cohort Size = 
CALCULATE(
    DISTINCTCOUNT(FactTransactions[CustomerID]),
    ALLEXCEPT(FactTransactions, FactTransactions[CohortMonth])
)
```

### [Cohort Active Customers]
Active customer count for a specific cohort month and activity index.
```dax
Cohort Active Customers = 
DISTINCTCOUNT(FactTransactions[CustomerID])
```

### [Cohort Retention Rate %]
Cohort retention rate percentage for matrix visualizations (Cohort Month rows vs. Cohort Index columns).
```dax
Cohort Retention Rate % = 
DIVIDE(
    [Cohort Active Customers],
    [Cohort Size],
    0
)
```

## 6. Dashboard Integration Quickstart in Power BI Desktop

1. **Connect to Data**:
   - In Power BI Desktop, select **Get Data** -> **More** -> **ODBC** or **Python script** / **Folder** (`output/`).
   - Import `transactions` (from SQLite or CSV), `output/rfm_customer_segments.csv`, and `output/customer_churn_predictions.csv`.
2. **Relationships**:
   - Link `FactTransactions[CustomerID]` 1-to-many to `DimCustomer[CustomerID]`.
   - Link `FactTransactions[InvoiceDate]` to `DimDate[Date]`.
3. **Card Visuals**:
   - Add KPI cards for `[Total Sales]`, `[Churn Rate %]`, `[At-Risk Revenue Exposure]`, and `[Historic CLV]`.
4. **Cohort Matrix Visual**:
   - Matrix visual with `CohortMonth` on Rows, `CohortIndex` on Columns, and `[Cohort Retention Rate %]` in Values with conditional formatting color scale.
5. **Customer Risk Table**:
   - Table visual showing `CustomerID`, `Customer_Segment`, `Churn_Probability`, `Risk_Level`, and `Monetary`.
